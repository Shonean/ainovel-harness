# 充分性消融：方法与结论

本文记录本项目最核心的一次实验：逐层充分性消融，以及它如何推翻了我们自己的路线假设。

## 实验设计

**问题**：五层阶梯里，到底哪几层真正影响生成质量？

**方法**：冻结模型与解码参数，只改变喂给模型的阶梯层数，跨三本书对照打分。

- A 档：仅 l1
- B 档：l1–l2
- C 档：l1–l3
- D 档：l4 场景节拍直出

**评分维度**（统一评分入口 `score()`，七维）：

| 维度 | 测什么 |
|------|--------|
| fact_recall | 字面锚点在成稿中的保真率 |
| char | 人物一致性 |
| plot | 情节推进度（plot_sim 相似度） |
| syn | 句式结构 |
| flavor | AI 味反向分（越低越好） |
| completion | 完成度审计（三振出局制） |
| composite | 综合分 |

## 结论

| 档位 | 提供的上下文 | composite |
|------|--------------|-----------|
| A | l1 | ~0.30 |
| B | l1–l2 | ~0.30 |
| C | l1–l3 | ~0.30 |
| **D** | **l4** | **0.67** |

1. **C−B≈0**：l3 及其上所有层，对生成质量没有可测量的增量贡献。
2. **l4 是唯一有效断点**（A/B/C 持平 ~0.30，D 跳到 0.67）。
3. **后续 A/B 验证证伪了补救方案**：把 l4 场景切分信息前移进 l3，新 C 档只涨 +0.005~+0.012（均值 +0.009，跨三书、同模型 doubao-seed-evolving 对照）——噪声级，不显著。

## 这个负结果改变了什么

原本的假设是"每层都该让模型用得更好"。实证结果推翻了它：

- l1–l3 的存在意义被重新定位为**作者确认流**（human-in-the-loop 审批节点）——它们的价值不在提升模型输出，而在给作者提供可介入、可修改的中间视图；
- l4 成为最小生成单元，工程优化全部集中在 l4 的节拍质量与锚点设计上。

## 评估地基的自我纠错

这套消融结论本身经历过一次险情：`fact_recall` 的引号匹配 bug 曾让其中一本书的结论失真。修复后我们做了两件事：

1. **ScorerParams 全量抽取**：把评分器的权重、阈值、ban 词表、LLM 审阅 prompt 抽成版本化 JSON，抽取前后同批样本分数必须一致——评分器本身成为可审计对象；
2. **Canary 对抗集**：15 条手写失败模式（堆对白、模板腔、流水账、翻译腔、数字漂移……），首战即检出评分器 **9 处放水**。

配套的 PromptOpt 框架（见 [ARCHITECTURE.md](ARCHITECTURE.md)）把"先让评分器可信，再优化 prompt"固化为两层共演化的训练纪律。

## 复现指引

- 场景验证集构造：六类场景（开篇/战斗/修炼/对话/转场/日常）分层抽样；
- 变体生成：同一场景按 faithful/vivid/terse 三角度改写，用于校准评分器区分度；
- 人类偏好标注：原文与变体确定性乱序展示，真实原文标注不下发前端，防止自证。
